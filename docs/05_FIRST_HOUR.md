## هدف ساعت اول
بازیکن باید بفهمد:
> پول کم است، هزینه‌ها واقعی‌اند ولی راه پیشرفت وجود دارد.

در پایان ساعت اول بازیکن باید:
1. کنترل‌ها را یاد گرفته باشد.
2. گوشی و پیام‌ها را دیده باشد.
3. اولین شغل را پیدا کرده باشد.
4. اولین شیفت را انجام داده باشد.
5. اولین حقوق را دریافت کرده باشد.
6. هدف ۱۵ میلیونی برای دکه را دیده باشد.

## جریان اصلی
| دقیقه واقعی | رویداد |
|---|---|
| 0-5 | بیدار شدن، آلارم، گوشی |
| 5-10 | آماده شدن، آینه، لباس، اتاق |
| 10-15 | پیام صاحبخانه، فشار مالی |
| 15-20 | خروج از خانه، دیدن محله |
| 20-27 | رسیدن به پاساژ / مغازه |
| 27-35 | مصاحبه کاری |
| 35-47 | اولین شیفت و مینی‌گیم |
| 47-52 | دریافت حقوق و انتخاب خرج |
| 52-58 | دیدن دکه / کیوسک برای اجاره |
| 58-60 | پیام رقیب/دوست و هدف بعدی |

## پیام‌های کلیدی
### صاحبخانه
> سلام، اجاره این ماه هنوز واریز نشده. تا آخر هفته مهلت داری.

### دوست
> شنیدم دنبال کاری. پاساژ موبایل‌سنتر یه فروشنده میخواد. بگو سامان فرستادت.

### کارفرما
> قبلاً کار کردی؟ اینجا کار شوخی نیست. یه شیفت آزمایشی، اگه خراب نکنی ادامه میدیم.
