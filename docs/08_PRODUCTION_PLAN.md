## هدف فعلی
ساخت اولین نمونه قابل بازی در ۹۰ روز.

## فاز ۰ - آماده‌سازی (مدت: ۱ تا ۲ هفته)
- نصب Unity 6.3 LTS و ساخت پروژه URP
- نصب Git و Git LFS
- ساخت پوشه‌های docs و data
- تعریف تسک‌ها و تست فونت فارسی / RTL
- **خروجی:** پروژه آماده، سندها داخل Git، اولین صحنه Greybox

## فاز ۱ - پروتوتایپ حرکت و تعامل (مدت: ۲ تا ۴ هفته)
- حرکت بازیکن و دوربین ایزومتریک
- Greybox اتاق و کوچه
- تعامل ساده، HUD اولیه، گوشی ساده، Save اولیه
- **خروجی:** بازیکن می‌تواند راه برود، گوشی باز کند، پیام بخواند و تعامل کند.

## فاز ۲ - Core Loop ساده (مدت: ۳ تا ۵ هفته)
- TimeService, NeedsService, EconomyService, JobService
- مینی‌گیم اول، دریافت حقوق، خرید غذا، پیام صاحبخانه
- **خروجی:** یک حلقه کامل از بیدار شدن تا دریافت حقوق.

## فاز ۳ - دموی ساعت اول (مدت: ۳ تا ۵ هفته)
- دیالوگ‌ها، پاساژ / مغازه، مصاحبه، شیفت اول، دکه هدف، خلاصه پایان روز، Clip Mode ساده
- **خروجی:** دموی ۲۰ تا ۶۰ دقیقه‌ای قابل تست.
