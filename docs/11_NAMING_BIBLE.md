## قانون اصلی
از نام برندهای واقعی استفاده نمی‌کنیم.

## نام‌های مجاز عمومی
- نارمک
- تجریش
- جمهوری
- ولیعصر
- خیابان‌های معروف عمومی
- مترو / اتوبوس / تاکسی اینترنتی به صورت کلی

## نام‌های پارودی پیشنهادی
| مرجع واقعی | پارودی پیشنهادی |
|---|---|
| اسنپ | تپرو / زودبر / شهررو |
| دیوار | تیوار / ستون / آگهی‌کده |
| علاءالدین | موبایل‌سنتر / پاساژ دیجیتال |
| فروشگاه زنجیره‌ای | رفاه‌مارکت / جانبوشاپ |
| بانک واقعی | بانک شهر / بانک آینده‌ساز |
| برند موبایل | برندهای خیالی (میوه‌فون، سام‌تک، نوکیاطور) |

## قانون دیالوگ
- کنایه اجتماعی مجاز است.
- توهین مستقیم ممنوع است.
- شوخی با فقر باید انسانی باشد.
- شوخی با ورشکستگی باید مسیر امید داشته باشد.
