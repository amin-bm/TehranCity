## ژانر

## دوربین
### گیم‌پلی
- ایزومتریک / بالا به پایین
- زوم محدود
- چرخش محدود یا ۹۰ درجه‌ای
- مناسب دیدن مغازه، مشتری‌ها و شهر

### دیالوگ‌های مهم
- دوربین مجازی سینماتیک
- زاویه نزدیک‌تر
- فریم مناسب برای کلیپ عمودی
- بدون نیاز به انیمیشن صورت کامل
- (رجوع شود به `docs/07_ADR/ADR-001-camera.md`)

## Core Loop
### لوپ روزانه
1. بیدار شدن
2. چک کردن گوشی
3. دیدن وضعیت پول، انرژی، استرس، گرسنگی
4. انتخاب فعالیت (کار / آموزش / خرید / استراحت / اجتماعی)
5. رفت و آمد
6. انجام شیفت کاری یا مدیریت مغازه
7. دریافت درآمد
8. خرج کردن یا پس‌انداز
9. خواب و ذخیره

### لوپ بلندمدت
1. کارمندی
2. پس‌انداز
3. خرید / اجاره دکه یا کیوسک
4. مدیریت مغازه کوچک
5. استخدام کارمند
6. باز کردن مغازه بزرگتر
7. رقابت اجتماعی آنلاین در فاز بعدی

## حالت‌های درگیری بازیکن
### ۱. مدیریت زمان
- کار کنم یا آموزش ببینم؟
- تاکسی بگیرم یا پیاده بروم؟
- استراحت کنم یا شیفت اضافه بزنم؟

### ۲. مدیریت پول
- غذا بخرم یا پس‌انداز کنم؟
- جنس بخرم یا دکور مغازه؟
- اجاره بدهم یا وام بگیرم؟

### ۳. مینی‌گیم‌های ساده
- فروشندگی
- صندوق
- چیدن قفسه
- پاسخ به مشتری

### ۴. داستان و دیالوگ
- صاحبخانه
- دوست
- کارفرما
- مشتری‌ها
- رقبا

## اصول طراحی
- هر سیستم باید در ۱۰ ثانیه قابل فهم باشد.
- فشار اقتصادی باید سخت ولی منصفانه باشد.
- بازیکن باید همیشه هدف بعدی را ببیند.
- شکست نباید Game Over سخت داشته باشد.
- هر لحظه مهم باید قابل تبدیل به میم باشد.
