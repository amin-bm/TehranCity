# ADR-006: Art Style
status: Approved
date: 2026-08-08
deciders: Project Lead

## مسئله
گرافیک رئال برای تیم کوچک پرهزینه و پرریسک است و انتظار واقع‌گرایی بالایی ایجاد می‌کند.

## تصمیم
سبک هنری **Stylized Low-Poly / Semi-Cartoon** انتخاب می‌شود.

## اصول
- استفاده از Assetهای آماده مجاز است اما باید یکدست شوند.
- گرافیک گیم‌پلی از انیمیشن‌های داستانی جدا است.
- حس تهران با نام‌ها، صدا، تابلو، دیالوگ و رنگ ساخته می‌شود نه با مدل‌های رئال.

## انیمیشن‌های داستانی
- Comic Panels
- Visual Novel Style (نیم‌تنه با متن)
- کاتسین ساده با Cinemachine

## پیامدها
### مثبت
- تولید سریع‌تر و اجرای سبک‌تر
- مناسب سیستم‌های ضعیف و Asset Store
- کاهش انتظار رئالیسم

### منفی
- سبک Assetها باید یکپارچه شود.

## معیار قبولی
- یک صحنه Greybox با چند Asset Stylized ساخته شود.
- از دوربین ایزومتریک خوانا باشد.
- حس محله با تابلو و صدا قابل تشخیص باشد.
