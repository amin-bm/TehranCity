# ADR-004: Prototype / MVP Scope
status: Approved
date: 2026-08-08
deciders: Project Lead

## مسئله
اسکوپ اولیه بسیار بزرگ بود (۳ محله، ۲ کاراکتر، ۸ تا ۱۲ شغل، Career + Sandbox، آنلاین و ...). این اسکوپ برای شروع غیر قابل جمع کردن بود.

## تصمیم
نمونه اولیه فقط شامل موارد زیر است:
| مورد | مقدار |
|---|---|
| محله | یک بلوک کوچک از نارمک |
| کاراکتر | فقط یک کاراکتر |
| شغل | یک شغل اصلی |
| مینی‌گیم | ۱ تا ۳ عدد |
| فضای داخلی | اتاق + مغازه/پاساژ کوچک |
| حالت | دموی خطی (Career) |
| آنلاین | بدون سرور، فقط معماری آماده |
| هدف تجربه | ۲۰ تا ۶۰ دقیقه |

## چیزهایی که حذف شدند
- سه محله کامل
- کاراکتر دوم
- Sandbox کامل
- بانک پیشرفته
- حمل و نقل کامل
- بازارچه و لیدربورد واقعی
- نسخه موبایل و Steam

## پیامدها
### مثبت
- ساخت سریع‌تر و کاهش هزینه هنری
- امکان تست Core Loop واقعی

### منفی
- محتوا در ابتدا کم است و باید بر اساس بازخورد گسترش یابد.

## معیار قبولی
دمو باید چرخه کامل (بیدار شدن -> پیام صاحبخانه -> پیدا کردن شغل -> انجام شیفت -> دریافت حقوق -> هدف ۱۵ میلیونی) را داشته باشد.
