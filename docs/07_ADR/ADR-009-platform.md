# ADR-009: Platform Priority
status: Approved
date: 2026-08-08
deciders: Project Lead

## مسئله
بازی باید سبک باشد و به کاربران زیادی برسد، اما UI/UX موبایل برای مدیریت مغازه و اقتصاد پیچیده است.

## تصمیم
- **پلتفرم اصلی:** PC / Windows
- **موبایل:** بعداً، در صورت موفقیت و اثبات دمو.

## حداقل سیستم هدف PC
- **CPU:** نسل ۷ اینتل یا معادل
- **RAM:** 8 GB
- **GPU:** GPU مجتمع جدید یا کارت ضعیف (2 GB VRAM)
- **Storage:** 2-4 GB

## اصول بهینه‌سازی
- Stylized Low-Poly
- URP
- Occlusion Culling / LOD
- تعداد محدود NPC
- UI ساده و سبک

## معیار قبولی
- دموی فعلی روی سیستم هدف با فریم قابل قبول اجرا شود.
- تنظیمات گرافیکی حداقلی وجود داشته باشد.
- Build ویندوزی سبک و پایدار باشد.
