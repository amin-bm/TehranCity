# ADR-005: Playable Character Count
status: Approved
date: 2026-08-08
deciders: Project Lead

## مسئله
دو کاراکتر قابل بازی در نمونه اولیه باعث دو برابر شدن هزینه دیالوگ، تست، انیمیشن، بالانس و صداگذاری می‌شود.

## تصمیم
در نمونه اولیه **فقط یک کاراکتر قابل بازی** است.

### کاراکتر پیشنهادی
- **نام:** آرش رضایی
- **سن:** ۲۲ ساله
- **تحصیلات:** فارغ‌التحصیل مدیریت بازرگانی
- **شروع:** نارمک
- **شغل اول:** فروشندگی موبایل
- **هدف:** رسیدن به اولین کسب و کار

### سرنوشت کاراکتر دوم
کاراکتر دوم بعد از اثبات دمو به عنوان آپدیت رایگان، DLC یا محتوای فصلی اضافه می‌شود.

## معیار قبولی
- فقط یک کاراکتر در دمو انتخاب‌پذیر باشد.
- تمام دیالوگ‌های اصلی برای همان کاراکتر نوشته شوند.
- ساختار داده طوری باشد که کاراکتر دوم بعداً قابل اضافه شدن باشد.
