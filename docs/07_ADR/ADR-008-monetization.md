# ADR-008: Monetization Strategy
status: Approved
date: 2026-08-08
deciders: Project Lead

## مسئله
هدف اولیه درآمد مستقیم نیست، بلکه وایرال شدن و نصب بالا بین ایرانی‌هاست.

## تصمیم
- **مدل فعلی:** Free Install First, Monetization Later, Fair IAP Only
- بازی اولیه رایگان نصب می‌شود.
- خریدها نباید Pay-to-Win مستقیم باشند.
- فروش مستقیم پول داخل بازی برای رقابت ممنوع یا بسیار محدود است.

## مدل‌های درآمدی مجاز برای آینده
- Battle Pass
- Cosmetics / آیتم‌های ظاهری محدود
- Time-saver محدود
- محله / شغل DLC
- Quality of Life

## مدل‌های پرخطر (ممنوع)
- فروش مستقیم پول برای رقابت
- فروش XP بدون سقف
- فروش ملک با مزیت اقتصادی قوی
- حراج واقعی با پول واقعی

## معیار قبولی
- در نسخه اولیه هیچ خرید واقعی لازم نباشد.
- طراحی اقتصادی طوری باشد که بعداً بتوان IAP منصفانه اضافه کرد.
