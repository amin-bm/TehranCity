# ADR-002: Game Engine
status: Approved
date: 2026-08-08
deciders: Project Lead

## مسئله
پروژه چند ساله است و نیاز به موتور پایدار دارد.

## گزینه‌ها
### A. Unity 2022 LTS
- **مزایا:** شناخته‌شده، منابع زیاد
- **معایب:** برای پروژه جدید در ۲۰۲۶ قدیمی‌تر است.

### B. Unity 6 LTS
- **مزایا:** مناسب پروژه بلندمدت، URP پایدار، ابزارهای جدیدتر
- **معایب:** برخی Assetها ممکن است نیاز به تست داشته باشند.

### C. موتور دیگر (Unreal / Godot)
- **نتیجه:** رد شد، چون تیم با Unity کار می‌کند و تغییر موتور ریسک بزرگ است.

## تصمیم
استفاده از **Unity 6.3 LTS + URP** تأیید شد.

## پیامدها
### مثبت
- پشتیبانی بلندمدت
- مناسب برای PC و احتمالاً موبایل در آینده
- URP برای پرفورمنس مناسب است.

### منفی
- پکیج‌ها باید با Unity 6 سازگار باشند.

## معیار قبولی
- پروژه با Unity 6.3 ساخته شود.
- URP فعال باشد.
- یک Build ویندوزی ساده بدون خطا اجرا شود.
